# Project 14 — DevGuard: Testing, Debugging, Optimization & Security

**Anant Sinha**

DevGuard is a responsive quality-control dashboard for web development release readiness. It provides an interactive checklist for testing, debugging, performance optimization, and security, plus a tabbed quick-reference panel.

## Features
- Release checklist grouped by Testing, Debugging, Optimization, and Security
- Progress bar, completion count, remaining checks, and risk label
- Quick reference tabs with useful tools and commands
- Reset checklist
- Express server, health endpoint, and checklist API endpoint
- Responsive layout

## Stack
Node.js, Express, HTML, CSS, vanilla JavaScript

## Setup
```bash
npm install
npm start
```
Open http://localhost:4000

Health check: http://localhost:4000/health
